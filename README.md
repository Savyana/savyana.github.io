# Savanna Neace — CS-499 Capstone ePortfolio

A GitHub Pages-ready static website with three capstone artifacts, original/enhanced source files, milestone narratives, and professional self-assessment.

## Publish

1. Create a **public** GitHub repository named `Savyana.github.io` under the `Savyana` account (or use an existing repository and adjust the resulting site URL).
2. Upload **the contents of this folder** to the repository root, preserving the directory structure. Do not upload only the outer ZIP.
3. On GitHub, open **Settings > Pages**. Set **Deploy from a branch**, branch `main`, folder `/(root)`; save. Deployment may take a few minutes.
4. Visit `https://savyana.github.io/` if you used the exact repository name above.
5. Update the Code Review section of `index.html` with your **real** review video link. Add it before your final submission. If you prefer, share an unlisted YouTube link.
6. Inspect every section and download link; test the Android project in Android Studio and the Python projects in compatible local environments. No full execution was carried out during website packaging.
